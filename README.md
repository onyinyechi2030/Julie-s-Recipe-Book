# Julie's Recipe Book v12

Responsive version for desktop, tablet, and mobile.

## Open
Extract the ZIP and open `index.html` in a modern browser.

## Responsive behavior
- Desktop: three-column recipe library where space allows.
- Tablet: two-column layout and compact filters.
- Phone: single-column cards, fixed bottom navigation, large touch targets, and a full-screen recipe reader.

All 301 recipes and app logic remain embedded in the single HTML file.
