# Julie’s Recipe Book — Version 14

This version has two deliberately different responsive interfaces:

- **Phone (620px and narrower):** compact app bar, search-first view, collapsible filter drawer, list-style recipe rows, floating bottom navigation, and full-screen recipe reader with Ingredients/Steps tabs.
- **Tablet and desktop:** the existing multi-column cookbook layout and two-column recipe detail view.

Open `index.html` directly. All 301 recipes, styles, and application logic are embedded in the file.
